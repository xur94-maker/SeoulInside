📉 Fluctuation never disappears — Feynman's key point

Individual-trial deviation (never shrinks, stays scattered within ±σ) Error of the running average (converges to 0 as trials pile up, ±σ/√t)
💡 The histogram looking like a perfect bell curve is the "error of the running average" shrinking — not the "randomness of each individual trial" shrinking. The dots in the graph above stay spread across the same width (±σ) no matter how many trials pile up. This is Feynman's key point: order does not appear because disorder disappears — it only looks smaller by comparison.
