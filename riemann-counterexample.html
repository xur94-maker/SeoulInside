What you're seeing

When σ = ½ (the critical line), the blue curve dips to zero at exactly the known Riemann zeros: t ≈ 14.13, 21.02, 25.01, 30.42, 32.93...

When σ ≠ ½, the curve oscillates but never reaches zero. The Riemann Hypothesis says this is true for every possible σ ≠ ½ — not just the ones you can try here.

Why this is hard

The Riemann zeta function ζ(s) is defined for complex numbers s = σ + it. Its non-trivial zeros — the points where ζ(s) = 0 — all appear to have real part exactly ½.

ζ(s) = 1 + 1/2ˢ + 1/3ˢ + 1/4ˢ + ... (for Re(s) > 1)

The functional equation extends ζ to the entire complex plane. All known zeros lie on the critical line Re(s) = ½. The Riemann Hypothesis says all non-trivial zeros do — not just the first 10 trillion.

This page uses a partial sum approximation (N = 500 terms) for illustrative purposes. The true ζ function requires analytic continuation — the values shown are accurate near the critical strip but are approximations, not exact computations.
