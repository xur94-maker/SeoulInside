How does this work?

The Chudnovsky algorithm computes 1/π from the series below. Each extra term locks in about 14 more correct digits — this is the same formula used in real world-record π computations.

1/π = 12 · Σ (-1)^k (6k)!(13591409+545140134k) / [(3k)!(k!)³ · 640320^(3k+3/2)]

Summing this series term by term would need a huge division at every step, so the terms are instead combined recursively in halves — a technique called binary splitting. All arithmetic runs as arbitrary-precision integers via JavaScript's BigInt, and the computation runs on a separate worker thread so the page never freezes.
