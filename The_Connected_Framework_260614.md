Every annihilation event produces exactly two photons. The photon-to-baryon ratio is determined by counting these events.

Antiparticle-ordinary matter annihilation at high energy:

p̄ + p → π⁺ + π⁻ + π⁰ + ... (hadronic channels)

The hadronic channel does not produce two 511 keV photons. It produces pions, which subsequently decay:

π⁰ → γ + γ (different energy: ~67.5 MeV each)
π⁺ → μ⁺ + ν_μ → e⁺ + ν_e + ν̄_μ + ν_μ

The photon count per annihilation event is different. The neutrino count is different. The energy distribution is different.

**The consequence for η:**

If a fraction f of early-universe annihilation events were antiparticle-matter rather than pair annihilation:

η = n_b / n_γ shifts. The direction depends on whether hadronic channels produce more or fewer photons per event — a quantitative calculation identified here as an open problem.
