Formula 6 — Riemann's Functional Equation

▼
$$\zeta(s) = 2^s \pi^{s-1} \sin\!\left(\frac{\pi s}{2}\right) \Gamma(1-s)\, \zeta(1-s)$$

Formula 7 — Completed Xi Function

# xi(s) == xi(1-s)

Formula 13 — von Mangoldt Function

▼
$$\Lambda(n) = \begin{cases} \log p & \text{if } n = p^k \\ 0 & \text{otherwise} \end{cases}$$
from sympy import factorint, log
def von_mangoldt(n):
    factors = factorint(n)
    if len(factors) == 1:
        return log(list(factors.keys())[0])
    return 0
VonMangoldt[n_] := If[PrimePowerQ[n], Log[FactorInteger[n][[1,1]]], 0]

Formula 14 — Second Chebyshev Function ψ(x)

▼
$$\psi(x) = \sum_{p^k \le x} \log p = \sum_{n=1}^{\infty} \Lambda(n) \mathbf{1}_{[1,x]}(n)$$
def psi(x):
    return sum(von_mangoldt(n) for n in range(1, int(x)+1))
Psi[x_] := Sum[VonMangoldt[n], {n, 1, Floor[x]}]

Formula 16 — Perron's Formula

▼
$$\sum_{n \le x} a_n = \frac{1}{2\pi i} \int_{c-i\infty}^{c+i\infty} f(s)\, \frac{x^s}{s}\, ds$$
perron = (1/(2*pi*I)) * Integral(f(s) * x**s / s, (s, c - I*oo, c + I*oo))

Formula 17 — Riemann's Explicit Formula (ψ(x))

▼
$$\psi(x) = x - \sum_{\rho} \frac{x^{\rho}}{\rho} - \log(2\pi) - \tfrac{1}{2}\log\!\left(1 - x^{-2}\right)$$
def psi_explicit(x, zeros):
    sum_rho = sum(x**rho/rho for rho in zeros)
    return x - sum_rho - log(2*pi) - 1/2*log(1 - x**(-2))
PsiExplicit[x_] := x - Total[x^#/# & /@ zetaZeros] - Log[2 Pi] - 1/2 Log[1 - x^{-2}]

Formula 18 — Explicit Formula for π(x)

▼
$$\pi(x) = \operatorname{li}(x) - \sum_{\rho} \operatorname{li}(x^{\rho}) + \int_x^{\infty} \frac{dt}{t(t^2-1)\log t} - \log 2$$
def pi_explicit(x_val, zeros):
    li_x = li(x_val)
    sum_rho = sum(li(x_val**rho) for rho in zeros)
    integral = Integral(1/(t*(t**2-1)*log(t)), (t, x_val, oo))
    return li_x - sum_rho + integral - log(2)
PiExplicit[x_] := LogIntegral[x] - Total[LogIntegral[x^#] & /@ zeros] + Integrate[1/(t(t^2-1)Log[t]), {t,x,Infinity}] - Log[2]

Formula 23 — Riemann-Siegel Formula

▼
$$\zeta\!\left(\tfrac{1}{2}+it\right) = \sum_{n=1}^{N} \frac{1}{n^{1/2+it}} + e^{-i\theta(t)} \sum_{m=1}^{M} \frac{1}{m^{1/2-it}} + O(t^{-1/4})$$
def riemann_siegel_approx(t):
    N = int(floor(sqrt(t/(2*pi))))
    sum1 = sum(1/n**(0.5+1j*t) for n in range(1, N+1))
    theta_t = (t/2)*log(t/(2*pi)) - t/2 - pi/8
    sum2 = sum(1/m**(0.5-1j*t) for m in range(1, N+1))
    return sum1 + exp(-1j*theta_t) * sum2
RiemannSiegelApprox[t_] := Module[{N = Floor[Sqrt[t/(2 Pi)]], theta},
  theta = t/2 Log[t/(2 Pi)] - t/2 - Pi/8;
  Sum[1/n^(1/2+I t), {n,1,N}] + E^(-I theta) Sum[1/m^(1/2-I t), {m,1,N}]]

Formula 29 — GUE Probability Density

▼
$$P(H)\, dH = \frac{1}{Z_n} \exp\!\left(-\tfrac{1}{2}\operatorname{tr}(H^2)\right) dH$$
def gue_pdf(H, Z_n):
    return (1/Z_n) * np.exp(-0.5 * np.trace(H @ H))
GUEProb[H_] := 1/Z[n] Exp[-1/2 Tr[H . H]]

Formula 30 — GUE Eigenvalue Joint PDF

▼
$$P(\lambda_1,\dots,\lambda_n) = \frac{1}{Z_n'} \prod_{1 \le i < j \le n} |\lambda_i - \lambda_j|^2 \prod_{k=1}^n e^{-\lambda_k^2/2}$$
def gue_joint_pdf(lambdas, Z_prime):
    n = len(lambdas)
    vandermonde = np.prod([(lambdas[i]-lambdas[j])**2 for i in range(n) for j in range(i+1,n)])
    gaussian = np.prod(np.exp(-np.array(lambdas)**2/2))
    return vandermonde * gaussian / Z_prime
jointPDF[λs_] := 1/Zprime[n] Product[(λs[[i]]-λs[[j]])^2, {i,n},{j,i+1,n}] Product[E^{-λ^2/2}, {λ,λs}]

Formula 41 — Gallagher's Method

▼
$$\zeta\!\left(\tfrac{1}{2}+it\right) \approx \sum_{n \le X} \frac{1}{n^{1/2+it}} + \chi\!\left(\tfrac{1}{2}+it\right) \sum_{m \le Y} \frac{1}{m^{1/2-it}}$$
def gallagher_approx(t, X, Y):
    sum1 = sum(1/n**(0.5+1j*t) for n in range(1, X+1))
    sum2 = sum(1/m**(0.5-1j*t) for m in range(1, Y+1))
    chi = (2*np.pi)**(1j*t) * gamma(0.5-1j*t)/gamma(0.5+1j*t)
    return sum1 + chi * sum2
GallagherApprox[t_, X_, Y_] := Sum[1/n^(1/2+I t), {n,1,X}] + Chi[1/2+I t] Sum[1/m^(1/2-I t), {m,1,Y}]
