🔢 Irrational Number Precision Calculator — True Arbitrary-Precision Newton's Method

The double-precision floating-point type hits its limit at about 15–16 digits, but this page uses BigInt-based fixed-point arithmetic to actually run Newton's method as many times as needed to reach the number of digits you want. It's not "in theory it should be accurate" — your browser really computes and displays every one of those digits.

Example: N=7, k=4 → fourth root of 7 (x⁴ = 7)
Newton's method roughly doubles the number of correct digits with each iteration. About 1,000 digits is nearly instant, 20,000 digits takes tens of ms, and 100,000 digits takes around a second (depending on your device). For very large values the screen may freeze briefly during computation, so the work is split into stages.
