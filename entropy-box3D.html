Positional entropy H / Hmax (per coarse-graining grid)

The solid line is the measured value; the dashed line is the expected value for a perfectly uniform random placement with the same N (including finite-sample bias). Equilibrium is reached when the solid line meets the dashed line. The vertical dashed line marks the moment of velocity reversal.

Boltzmann entropy S/kB = ln W

The logarithm of the number of microstates W = N! / ∏ nᵢ! for the occupation numbers of the middle grid. It is an extensive quantity that grows in proportion to N; the dashed line is the equilibrium expectation.

Speed distribution vs 3D Maxwell–Boltzmann

Measured (distribution shaped by collisions)Theory (Maxwell distribution)

The x-axis is speed/vrms and the y-axis is the bin probability. Since energy is conserved, the theoretical curve is recomputed from the current energy. If all particles start with the same speed, the histogram starts as a single bar and spreads toward the theoretical curve through collisions (Boltzmann’s H-theorem).

What is measured. The box is divided into n×n×n cells, and the Shannon entropy H = −Σ pi ln pi is computed from the fraction pi of particles in each cell. The cell size (coarse-graining) defines “which macrostates are distinguished”, so it is normal for the curves to differ between grids.
Why isn’t the dashed line at 1? With a finite sample, the plug-in entropy comes out lower by about (M−1)/(2N) on average (M is the number of cells; the Miller–Madow correction term). The dashed line on this page is computed from an exact binomial sum, not an approximation. At high density the hard core suppresses density fluctuations, so the true equilibrium line may sit slightly above the dashed line.
Physics model. Newtonian mode uses elastic hard spheres of equal mass. The collision instant is computed exactly within a step (the contact time τ is found by solving a quadratic, the particles are rewound, and the normal velocity components are exchanged), so momentum and energy are conserved, and wall reflection is a reversible mirror reflection. It is not a fully event-driven scheme, so multiple collisions overlapping within one step are approximated; increasing the collision passes removes almost all residual overlap. Reducing dt lowers the error further.
Velocity reversal (Loschmidt). After reversal, the entropy retraces its path back down. However, because of chaos, errors grow exponentially, so the longer you wait before reversing, the less well the initial state is recovered, and the entropy soon rises again. Increasing the perturbation ε makes this breakdown come much sooner. In 3D the effect is even more dramatic than in 2D.
Wall pressure. The pressure readout is computed from the impulse delivered to the walls: every reflection transfers 2m|vn| (vn = velocity component normal to the wall). With this definition, an ideal gas gives P·V/(N kBT) = 1 exactly. The readout is only defined for reflecting walls (no wall pressure exists under periodic boundaries).
Limitations. As the packing fraction approaches φ≈0.49 (the hard-sphere freezing transition), the system is no longer a simple fluid. For this reason the upper limit of N is capped at φ≤0.45. The stochastic random-walk mode is not implemented in 3D; only the Newtonian hard-sphere model is available.
