Feel the Hardness

Why the most important unsolved problem in computer science has resisted 50 years of the sharpest minds — demonstrated in your browser, in real time.

The P vs NP question asks: if a solution can be verified quickly, can it also be found quickly? Every experiment below shows the same answer — not yet proven, but viscerally felt.

Run each experiment. Watch the time column. That explosion — from milliseconds to geological epochs — is the problem.

Subset Sum NP-Complete

Given a set of integers, does any subset sum to exactly zero? Verifying a solution takes a millisecond. Finding one requires checking 2ⁿ subsets. Watch what happens as n grows.
