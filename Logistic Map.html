How to read this page

There is just one rule. Start at 0, square it, add c, then repeat with the result. Once the distance from the center exceeds 2, the value is guaranteed to fly off to infinity, so that moment is recorded as an “escape.”

  • Orbit cloud: Choose “Orbit cloud (bifurcation)” to see the view from the Logistic Map / Mandelbrot video. The floor is the Re c / Im c plane as usual, and for every c the values Re zn that the iteration settles into are stacked vertically (points that escape are left dark). From the top it looks like the Mandelbrot set; use “Side view” and it becomes the logistic-map bifurcation diagram, because on the real axis z → z² + c is equivalent to the logistic map.
  • Height modes: “Potential” uses the Douady–Hubbard potential, a smooth continuous function that is 0 on the Mandelbrot set and grows steadily outside it, so the set sits on a flat plateau at the top of a smoothly curved surface (inverted so the set is high). The other modes stand up the escape step count instead.
  • Landscape (left): Each point is one value of c. The height is how many steps it took to escape (smoothed into a continuous value), and points that survive to the end become a flat plateau. The plateau is the Mandelbrot set.
  • k slider: Only points that survive k steps count as plateau. As you increase k, you can watch the boundary grow more complex, starting from a small disk. The play button is the same scene as the GIF in section 7 of the article.
  • Real axis: Choose “Cut as cross-section” and the landscape is sliced along the line Im c = 0. The stretch where the plateau stays connected in the cross-section is the −2 ≤ c ≤ ¼ of section 5 of the article.
  • Journey (upper right): The floor is the complex plane, and the step count rises as you go up. The red ring and translucent wall on the floor mark the distance-2 boundary. Piercing the wall means escape. c = 0.25 looks like a spiral converging to a single point, and c = −1 looks like a back-and-forth between two points.
  • Julia set: The picture you get by using the same c while varying the starting point. The center of the dashed cross is 0, the start of the Mandelbrot journey, and the pink dots are that journey. If the journey of 0 does not escape, the Julia set is a single connected piece; if it escapes, the Julia set is scattered dust.
  • Turn on Drag c and rub over the landscape: c moves continuously, so you can watch the Julia set shatter from a single piece into dust. The arrow keys (with Shift) also move c.

Computation settings: Resolution is the number of landscape grid points, and max iterations is the per-point computation limit. All CPU threads (Web Workers) share the work, and the Julia set gets sharper with the resolution too. Zooming in automatically raises the required iteration count. Because of the double-precision (64-bit) limit, you cannot zoom in beyond roughly 10¹³×.

The 3D height is “stood up to look good.” It is a different object from the Mandelbulb, which extends the multiplicative structure of complex numbers into three dimensions.
