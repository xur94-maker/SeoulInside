삼차함수의 대칭성과 비율

왜 이런 일이 일어나는가

친한 친구와 식사하면서 대화 중 엉뚱하게도 3차 함수의 성질에 관한 대화를 하게 되었습니다. 친구의 질문은 3차 함수도 2차 함수처럼 일정한 대칭성이 있는가라는 부분이었습니다.

2차 함수의 경우는 직관적으로 대칭성을 보입니다. 3차 함수의 경우는 직관적으로 보이지 않을 수는 있지만, 그것을 미분한 2차 함수의 대칭성이 명확하기 때문에 그 적분 관계에 있는 3차 함수 또한 대칭성을 보이게 됩니다. 재미있게도 이 문제는 대한민국 입시에서 자주 등장하는 것으로 알려져 있습니다.

그래서 오늘은 재미삼아 이 문제에 대해 써보게 되었습니다.

TL;DR 삼차함수는 그것을 미분한 2차함수의 꼭짓점의 x값을 기준으로, (x, f(x)) 값을 기준으로 점대칭성을 보이게 됩니다. 그 지점은 삼차함수의 양쪽 극값을 연결한 선과 삼차함수가 만나는 점이기도 합니다.

직접 만져보세요

계수를 바꿔도 성질이 항상 성립하는지 확인해보세요

1. 왜 삼차함수만 이런가 — 차수별 비교

삼차함수의 대칭성을 이해하기 전에, 먼저 이런 의문이 들어야 합니다.

"왜 하필 삼차함수만 점대칭인가? 일차, 이차, 사차는 왜 다른가?"

이 질문에 먼저 답해두면, 이후의 모든 증명이 "그래서 삼차는 특별하다"는 맥락을 얻습니다.

차수대칭성이유
일차점대칭 (모든 점)직선
이차선대칭 (축)x² 계수만 남음
삼차점대칭 (변곡점)x³이 기함수, x² 제거 가능
사차일반적으로 대칭 없음x³ 항이 남아 비대칭

핵심은 "낮은 차수 항을 제거한 뒤 무엇이 남는가"입니다.

삼차함수는 x² 항을 평행이동으로 제거하면 x 항은 그대로 남습니다. 남는 건 "x³ + x, 즉 홀수 차수 항들"이고, 이건 기함수입니다. 그래서 점대칭이 성립합니다.

사차함수는 x³ 항을 평행이동으로 제거해도, 일반적으로는 x 항까지 남아 비대칭이 됩니다. x 항까지 함께 사라져서 "x⁴ + x², 즉 짝수 차수 항들"만 남는 우함수가 되는 경우는, 계수들 사이에 특정 관계(극값이 등간격, 즉 도함수인 삼차함수의 대칭 중심이 x축 위에 있는 경우)가 성립하는 특수한 경우뿐입니다. 그래서 사차함수는 일반적으로 y축 대칭(선대칭)조차 보장되지 않고, 점대칭은 더더욱 일반적으로 성립하지 않습니다.

즉 삼차는 "항상 홀수 차수만 남는" 형태가 되지만, 사차는 "특정 조건에서만 짝수 차수만 남는" 형태가 됩니다. 이 차이 — 항 하나를 제거했을 때 다른 항이 항상 같이 사라지느냐, 아니면 계수들 사이의 추가 조건이 있어야만 사라지느냐 — 가 삼차와 사차의 대칭 방식을 가르는 진짜 이유입니다. (구체적인 치환 계산은 아래 1장의 증명에서 직접 확인합니다.)

즉, 삼차함수는 "가장 단순한 비선형 함수이면서, 대칭성과 비선형성이 공존하는 첫 번째 예"입니다. 이 위치가 삼차함수를 입시에서도, 수학 전체에서도 특별하게 만듭니다.

2. 큰 그림: 두 개의 관점

삼차함수의 점대칭성은 완전히 다른 두 재료로 각각 증명할 수 있습니다. 이게 중요한 이유는, 같은 결론에 전혀 다른 길로 도착한다는 사실 자체가 "이 대칭성이 우연이 아니라 구조 깊숙이 박혀있다"는 증거이기 때문입니다.

관점 1: 대수적 관점 — x² 항을 지워버리기

일반적인 삼차함수 f(x) = ax³ + bx² + cx + d에서, 적절히 평행이동하면 x² 항을 완전히 소거할 수 있습니다. 그러면 함수는 "기함수 + 상수" 형태가 됩니다. 기함수는 원점 대칭이고, 상수를 더해도 대칭 중심이 위로 올라갈 뿐 대칭성 자체는 유지됩니다.

관점 2: 미분적 관점 — 도함수는 포물선이다

f(x)를 미분한 f'(x) = 3ax² + 2bx + c는 이차함수, 즉 포물선입니다. 포물선은 자기 꼭짓점(대칭축)에 대해 항상 좌우대칭입니다. 그리고 그 꼭짓점의 x좌표는 −b/(3a)로, 변곡점의 x좌표와 정확히 일치합니다.

두 관점의 관계: 관점 1은 "함수 자체를 원점으로 옮겨서 홀함수로 만드는" 대수적 접근이고, 관점 2는 "도함수의 대칭성에서 출발하는" 미분적 접근입니다. 완전히 다른 재료로 같은 곳에 도착합니다.

3. 대칭성이 있으면 무엇이 따라오는가

점대칭성은 그 자체로도 아름답지만, 입시에서 강력한 진짜 이유는 여기서 수많은 비례 관계가 파생되기 때문입니다. 대칭성은 씨앗이고, 비례 관계는 그 씨앗에서 자라나는 줄기들입니다.

(1) 함수값의 대칭 관계

대칭 중심을 x₀라 하면, 다음이 항상 성립합니다.

f(x₀ − t) + f(x₀ + t) = 2f(x₀)

문제에서 f(p − q) = f(p + q) 같은 조건이 주어지면, 이건 "함수가 x = p에서 변곡점을 가진다"는 신호입니다.

(2) 미분값의 대칭 관계

f'(x₀ − t) = f'(x₀ + t)

(3) 극값점의 대칭

x₁ + x₂ = 2x₀

이것이 모든 비례 관계 문제의 출발점입니다. 여기서 "1:1:1 삼등분"도, "1:√3"도, "5점 등간격"도 전부 파생됩니다.

(4) 적분의 대칭 관계

변곡점 기준으로 좌우 대칭 구간의 적분 차이가 단순해집니다. 넓이 문제에서 이 성질이 계산을 극적으로 줄여줍니다.

4. 파생되는 비례 관계들의 지도

대칭성이라는 씨앗에서 어떤 줄기들이 자라나는지 미리 지도를 그려두겠습니다.

① 1:1:1 삼등분 관계

극값을 가지는 삼차함수에서, 변곡점의 가로 좌표를 중심으로 인접한 네 개의 중요한 가로 좌표는 등차수열을 이룹니다.

−2k, −k, 0, k (변곡점을 원점으로 뒀을 때)

② 1:√3 비율

변곡점을 지나고 x축에 평행한 직선과 삼차함수 그래프의 교점의 가로 좌표와 극값점의 가로 좌표 사이에는 1:√3 관계가 존재합니다.

③ 접선에 의한 2:1 관계

극값점을 지나는 수평 접선이 함수와 다시 만나는 점까지, 변곡점을 기준으로 잰 거리는 극값점과 변곡점 사이 거리의 2배가 됩니다. (다시 만나는 그 점은 접점이 아니라 단순 교점입니다.)

④ 5점 등간격 (1:2 확장판)

−2k, −k, 0, k, 2k

⑤ 넓이 공식

S = |a|/12 × |β − α|⁴

⑥ 극값의 높이 차 공식

극값의 차 = |a| · d³ / 2

5. 시험에서 이게 강력한 이유

이 대칭성과 비례 관계가 입시에서 결정적인 이유는 세 가지입니다.

첫째, 계산량이 극적으로 줄어듭니다. 복잡한 극값 계산 문제에서 1:1:1 비율을 직접 사용하여 미지수를 설정하면, 연립방정식을 풀 필요 없이 몇 줄로 끝납니다.

둘째, 여러 개념을 통합적으로 요구합니다. 미분, 적분, 방정식의 근과 계수의 관계가 한 문제 안에서 얽혀 있어, 변별력이 높습니다.

셋째, 접근 방식이 정형화되어 있습니다. 문제 조건에서 대칭 신호가 보이면, 아래 한 가지 절차로 거의 모든 유형이 풀립니다.

대칭 조건이 보인다 → 변곡점을 원점으로 이동 → 기함수 형태로 정리 → 인수분해

이제 하나의 구체적인 삼차함수를 끝까지 재사용하면서, 매 성질마다 숫자로 먼저 확인하고 왜 그런지 증명해봅니다.

0. 앞으로 계속 쓸 예시 하나

다음 함수를 기준으로 삼겠습니다.

f(x) = x³ − 6x² + 9x + 2
  • x = 0 일 때, f(0) = 2
  • x = 1 일 때, f(1) = 6 ← 극댓값
  • x = 2 일 때, f(2) = 4 ← 변곡점
  • x = 3 일 때, f(3) = 2 ← 극솟값

x = 0, 1, 2, 3 이 등간격(간격 1)으로 놓여 있고, 값은 2, 6, 4, 2 라는 걸 기억해두세요. 이 숫자들이 뒤에서 계속 등장합니다.

1. 모든 삼차함수는 대칭이다

눈으로 먼저 확인하기

변곡점 x = 2 를 기준으로 좌우로 1만큼 떨어진 두 점을 봅시다.

  • f(2 − 1) = f(1) = 6
  • f(2 + 1) = f(3) = 2
  • 평균: (6 + 2) / 2 = 4 = f(2)

f(2 − t) + f(2 + t) = 2 × f(2) — 이 관계가 모든 t에 대해 성립합니다. 이게 바로 "점대칭"입니다.

증명 1: 대수적 증명 — x² 항을 지워버리기

f(x) = ax³ + bx² + cx + d 에서 x = t − m (단, m = b/(3a))으로 치환하면, t의 각 차수별 계수는:

t³ 의 계수: a t² 의 계수: −3am + b t¹ 의 계수: 3am² − 2bm + c t⁰ 의 계수: −am³ + bm² − cm + d

t² 계수를 확인하면 −3am + b = −3a·(b/3a) + b = −b + b = 0. 문자로 계산해도 정확히 0입니다 — 모든 삼차함수에서 이 치환을 하면 t² 항이 사라집니다.

치환 결과 g(t) = a·t³ + p·t + q 형태가 되고, g(−t) = −at³ − pt + q 이므로 g(t) + g(−t) = 2q. 이건 g(t)의 그래프가 점 (0, q) 에 대해 점대칭이라는 뜻입니다.

증명 2: 미분적 증명 — 도함수(포물선)의 대칭성 이용

f'(x) = 3ax² + 2bx + c는 포물선이고, 꼭짓점 x좌표는 −b/(3a) — 변곡점의 x좌표와 정확히 같습니다.

x₀ = −b/(3a) 라 하면 f'(x₀+t) − f'(x₀−t) = 4t(3a·x₀ + b) = 4t(−b+b) = 0 이 모든 a, b, c, t에 대해 성립합니다.

k(t) = f(x₀+t) + f(x₀−t) − 2f(x₀) 로 두면, k'(t) = f'(x₀+t) − f'(x₀−t) = 0 이므로 k(t)는 상수함수이고 k(0)=0 이니 k(t)는 항상 0 — 증명 1과 똑같은 결론에 도착합니다.

2. "1:1:1" 삼등분

눈으로 먼저 확인하기

x = 0, 1, 2, 3 은 간격이 전부 1로 똑같습니다. x = 0 → f(0) = 2, x = 3 → f(3) = 2 (극솟값). 극값과 똑같은 함숫값을 가지는 점이, 정확히 등간격 위치에 하나 더 있습니다.

왜 그런가 (증명)

g(t) = at³ + pt, 극값점 t=±k. g(t)=g(k) 를 풀면 (t−k)[a(t²+tk+k²)+p]=0, 극값 조건 p=−3ak² 대입하면 t²+tk−2k²=0 → (t−k)(t+2k)=0.

따라서 t = −2k 라는 해가 나오고, 네 점의 가로 좌표는 −2k, −k, 0, k — 간격이 전부 k로 똑같습니다. (원래 인수 (t−k)와 방금 나온 (t−k)를 합치면 전체는 (t−k)²(t+2k)=0 — t=k가 중근인 건 "자기 자신과 값이 같은 점"이니 당연하고, 그래서 새로 나오는 근은 t=−2k 하나뿐입니다.)

3. "1 : √3"

눈으로 먼저 확인하기

변곡점 (x=2, y=4)를 지나는 수평선 y=4 와 곡선의 교점을 구하면 x = 2, 2−√3, 2+√3. 극값점까지의 거리는 1, 교점까지의 거리는 √3 — 정확히 1:√3 비율입니다.

왜 그런가 (증명)

g(t)=at³−3ak²t=0 → t=0, t=±√3k. 극값 조건 t²=k², 교점 조건 t²=3k². t²의 비율이 1:3이니 t 자체의 비율은 1:√3 입니다.

4. 넓이 공식 — 계산 없이 넓이 구하기

(여기서 나오는 "접점 x=1, 재교점 x=4" 관계가 위 지도의 ③ 접선에 의한 2:1 관계입니다 — 변곡점(x=2) 기준으로 재교점까지 거리는 2, 극값점까지 거리는 1이니 정확히 2:1이죠.)

눈으로 먼저 확인하기

극댓값 (x=1, y=6)에서의 접선 y=6 은 x=1(접점)과 x=4(교점)에서 곡선과 만납니다.

S = |a| / 12 × |β − α|⁴ = 1/12 × 3⁴ = 81/12 = 6.75

완전한 증명 — 실제로 적분하기

∫[α→β] a(x−α)²(x−β) dx 를 u = x−α 로 치환하고 d=β−α 라 하면:

= a ∫[0→d] (u³ − du²) du = a(d⁴/4 − d⁴/3) = −a·d⁴/12

넓이는 절댓값을 씌워 S = |a|/12 × |β−α|⁴. α, β, a가 무엇이든 항상 성립합니다.

5. 1:√3의 확장판 — 등간격 점이 5개까지 늘어난다

눈으로 먼저 확인하기

극솟값(x=3, y=2)을 지나는 수평 접선은 x=0에서 다시 만납니다. 정리하면 x = 0, 1, 2, 3, 4 다섯 점이 전부 간격 1로 등간격입니다.

결국 1:1:1을 좌우 양쪽에서 각각 적용했더니, 자연스럽게 5점 등간격 구조가 됩니다. 새로운 원리가 아니라, 같은 원리를 양쪽에 다 적용한 결과입니다.

6. 극값의 차 공식 — 계산 없이 높이 구하기

눈으로 먼저 확인하기

극댓값 f(1)=6, 극솟값 f(3)=2, 차이는 4. 극값점 사이 거리는 2.

극값의 차 = |a| × (극값점 사이 거리)³ / 2 = |1| × 2³ / 2 = 4

왜 그런가 (증명)

g(t)=at³+pt 에서 g(k)=−g(−k) (기함수이므로). 어느 쪽이 극댓값·극솟값인지는 a의 부호에 따라 달라지지만, "차이"의 절댓값만 보면 |g(k)−g(−k)| = |2ak³+2pk|. 극값 조건 p=−3ak² 대입 → |−4ak³| = 4|a|k³. 거리 d=2k, k=d/2 대입하면 4|a|(d/2)³ = |a|·d³/2.

7. 실전 문제 시뮬레이터

지금까지 배운 도구들을 실제로 써봅시다. 조건을 바꿔가며 직접 풀어보세요.

실전 시뮬레이터

최고차항 계수 · 변곡점 · 극값의 차 → 넓이

최고차항의 계수가 a인 삼차함수 f(x)의 그래프가 점 (x₀, y₀)에서 변곡점을 가진다. 이 함수의 두 극값의 차가 Δ일 때, 극댓값에서의 접선과 곡선 y=f(x)로 둘러싸인 부분의 넓이를 구하시오.

8. 정리

지금까지 본 성질들을 한 줄씩 요약하면:

  • 점대칭: x² 항을 평행이동으로 없애면 기함수+상수가 되기 때문에 필연적으로 발생
  • 1:1:1: g(t)=g(k) 라는 삼차방정식이 (t−k)(t+2k)로 인수분해되기 때문에 발생
  • 1:√3: 극값 조건(t²=k²)과 변곡점을 지나는 수평선과의 교점 조건(t²=3k²)의 제곱 비율이 1:3이기 때문에 발생
  • 넓이 공식: 접점의 중근 구조 (x−α)²(x−β) 를 적분하면 항상 4제곱 형태로 정리되기 때문에 발생
  • 5점 등간격: 좌우 극값의 수평 접선을 각각 적용하면 −2k,−k,0,k,2k 다섯 점이 나오기 때문에 발생
  • 극값의 차: 극값이 ±2ak³ 형태로 나오고, 거리 d=2k를 대입하면 |a|d³/2 로 정리되기 때문에 발생
